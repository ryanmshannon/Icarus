SDSS g/r/i total-system photon-counting response curves ("SLOAN/SDSS.g",
"SLOAN/SDSS.r", "SLOAN/SDSS.i"), downloaded from the SVO Filter Profile
Service:

    http://svo2.cab.inta-csic.es/theory/fps/getdata.php?format=ascii&id=SLOAN/SDSS.<band>

Two columns: wavelength (Angstrom), response (dimensionless, photon-counting
convention). Used by build_atmo_grid_J2241-5236.py to build the photometric
atmosphere grids for model_J2241-5236.py.
